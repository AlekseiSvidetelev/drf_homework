# DRF Homework Project

## Запуск проекта с Docker Compose
Прежде чем начинать, убедитесь, что у вас установлены программы Docker и Docker Compose. Их можно скачать бесплатно на официальном сайте Docker.

### Запуск проекта.
Откройте окно терминала или командной строки.
Перейдите в папку с проектом, где находится файл docker-compose.yaml.
Напишите в терминале такую команду и нажмите Enter:

`docker-compose up -d --build`

Эта команда запустит все необходимые контейнеры (это как отдельные маленькие компьютеры внутри большого компьютера) в фоновом режиме.

### Проверка, что всё работает.
Чтобы убедиться, что всё запущено, напишите в терминале такую команду:

`docker-compose ps`

Если увидите надпись вида "Running" напротив каждого контейнера, значит всё ОК.

### Как пользоваться проектом
Сервер вашего проекта доступен по адресу localhost:8000 в браузере. Зайдите на сайт и убедитесь, что страницы открываются.
Если вдруг понадобится закрыть проект, выполните такую команду:

`docker-compose down`

Она остановит все контейнеры и освободит память компьютера.

# Настройка сервера для деплоя
Подготовьте сервер (Ubuntu 22.04/24.04) и установите все необходимое

## Настройка сервера
Обновление системы
Обновление списка пакетов:
`sudo apt update`
Обновление всех установленных пакетов до их последних версий:
`sudo apt upgrade`

## Установка Git
Откройте терминал на сервере и выполните команду:
`sudo apt update`
`sudo apt install git`

Убедитесь, что Git установлен корректно, выполнив команду:
`git --version`

Клонирование репозитория с GitHub
Перейдите в директорию, где вы хотите разместить код вашего приложения. Например:
`cd /var/www`

Настройте сервер и GIT для подключения по SSH ключу

Затем выполните команду для клонирования репозитория:
`git clone https://github.com/username/repository.git`

Запуск контейнеров
Перейдите в директорию, где находится ваш файл docker-compose.yml. Например:
`cd /var/www/repository`
Выполните команду для запуска контейнеров:
`docker-compose up -d`

## В настройках репозитория добавьте следующие секреты:

`SERVER_IP` — IP-адрес вашего сервера.
`SSH_USER` — имя пользователя для SSH-подключения.
`SSH_KEY` — приватный SSH-ключ для аутентификации.
`DEPLOY_DIR` — директория на сервере, где будет размещено приложение.

## CI/CD

При каждом `push` в ветку GitHub Actions автоматически:

1. Запускает проверку **flake8**  
2. Выполняет **pytest**  
3. Собирает **Docker-образ** и публикует его на **Docker Hub**  
4. Подключается по SSH к серверу, обновляет код и **перезапускает контейнеры**
